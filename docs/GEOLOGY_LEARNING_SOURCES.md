# Geology vocabulary sources

Reviewed 7 October 2026. This reference contains original short explanations
and observation prompts for reading geological map wording. It contains no
copied passages, photographs, specimen identifications, formations invented
from a location, or predictions about finds.

## Material concepts

The vocabulary contains 28 material concepts and 28 age labels.

| Concept | Factual basis |
| --- | --- |
| Sand | [NPS sedimentary rocks](https://www.nps.gov/subjects/geology/sedimentary.htm): grain size relative to silt and gravel; loose sediment versus consolidated rock. |
| Gravel | [USGS thesaurus](https://apps.usgs.gov/thesaurus/thesaurus-full.php): loose fragments, pebbles and cobbles. |
| Silt | [NPS sedimentary rocks](https://www.nps.gov/subjects/geology/sedimentary.htm): grain size between clay and sand. |
| Clay | [USGS lithologic classification](https://apps.usgs.gov/thesaurus/thesaurus-full.php?thcode=4): fine sediment and clay minerals are related but distinct usages. |
| Alluvium | [USGS water glossary](https://water.usgs.gov/water-basics_glossary.html): sediment deposited by flowing water. [USGS transported stream cobbles study](https://www.usgs.gov/publications/jasperoid-float-and-stream-cobbles-tools-geochemical-exploration-hydrothermal-ore): loose fragments can travel downstream from their source. |
| Glacial till | [USGS water glossary](https://water.usgs.gov/water-basics_glossary.html): unsorted sediment deposited directly by glacier ice. [USGS glacier glossary](https://pubs.usgs.gov/of/2004/1216/text.html): glacier transport of rock fragments from their origin. |
| Loess | [USGS water glossary](https://water.usgs.gov/water-basics_glossary.html): wind deposited fine sediment. [USGS eolian sediments](https://www.usgs.gov/publications/eolian-sediments-0): transport and varied origins of loess. |
| Shale | [USGS lithologic classification](https://apps.usgs.gov/thesaurus/thesaurus-full.php?thcode=4): very fine rock particles and thin layering. |
| Siltstone | [USGS lithologic classification](https://apps.usgs.gov/thesaurus/thesaurus-full.php?thcode=4): predominantly silt particles; distinction from shale's thin splitting. |
| Sandstone | [USGS sandstone definition](https://apps.usgs.gov/thesaurus/term-simple.php?code=2.1.3&thcode=4), [NPS sedimentary rocks](https://www.nps.gov/subjects/geology/sedimentary.htm): sand grains consolidated into rock. |
| Mudstone | [USGS lithologic classification](https://apps.usgs.gov/thesaurus/thesaurus-full.php?thcode=4): broad fine sediment rock name when clay/silt proportions are unspecified. |
| Limestone | [USGS lithologic classification](https://apps.usgs.gov/thesaurus/thesaurus-full.php?thcode=4): chiefly calcium carbonate/calcite. [NPS sedimentary rocks](https://www.nps.gov/subjects/geology/sedimentary.htm): some limestone originates in organisms; this does not establish fossil content of an individual specimen. |
| Dolostone / dolomite | [USGS dolostone definition](https://apps.usgs.gov/thesaurus/term-simple.php?code=2.2.2&thcode=4), [USGS dolomite overview](https://pubs.usgs.gov/sir/2017/5118/elements/Dolomite/Dlmt_txt.html): dolomite is a mineral; the word also denotes rock rich in that mineral. |
| Conglomerate | [USGS conglomerate definition](https://apps.usgs.gov/thesaurus/term-simple.php?code=2.1.5&thcode=4): gravel sized rounded to partly rounded fragments consolidated into rock. |
| Basalt | [NPS igneous rocks](https://www.nps.gov/subjects/geology/igneous.htm): volcanic origin, typical fine texture/dark appearance, possible gas cavities. |
| Granite | [NPS igneous rocks](https://www.nps.gov/subjects/geology/igneous.htm): cooling underground, quartz/feldspar, commonly visible crystals. |
| Schist | [NPS metamorphic rocks](https://www.nps.gov/subjects/geology/metamorphic.htm), [NPS geology teacher guide](https://www.nps.gov/romo/learn/education/upload/Geology-Teacher-Guide-for-web.pdf): mineral alignment and common visible mica. |
| Gneiss | [NPS geology teacher guide](https://www.nps.gov/romo/learn/education/upload/Geology-Teacher-Guide-for-web.pdf): mineral bands. |
| Volcanic ash | [NPS pyroclasts](https://www.nps.gov/subjects/volcanoes/pyroclasts.htm): tiny erupted rock/mineral/glass fragments. |
| Tuff | [NPS pyroclasts](https://www.nps.gov/subjects/volcanoes/pyroclasts.htm): consolidated volcanic fragments, chiefly ash. |
| Chert | [USGS chert discussion](https://pubs.usgs.gov/of/2004/1098/): predominantly microscopic quartz. |
| Quartzite | [USGS lithologic classification](https://apps.usgs.gov/thesaurus/thesaurus-full.php?thcode=4), [NPS metamorphic rocks](https://www.nps.gov/subjects/geology/metamorphic.htm): quartz rich metamorphic rock, commonly from recrystallized sandstone. |
| Sedimentary rocks / sedimentary | [NPS sedimentary rocks](https://www.nps.gov/subjects/geology/sedimentary.htm): broad family formed from sediment, organisms, or chemical precipitation. This wording alone does not specify a rock type. |
| Unconsolidated | [USGS water glossary](https://water.usgs.gov/water-basics_glossary.html): loose or loosely bound sediment. |
| Mud | [USGS usSEABED questions](https://pubs.usgs.gov/ds/2005/118/htmldocs/faqs.htm): broad silt/clay grouping when separate proportions are unavailable. |
| Chalk | [Kansas Geological Survey rock reference](https://www.kgs.ku.edu/Publications/Bulletins/ED2/03_rocks.html): soft, porous, fine limestone; impurities can affect color. |
| Igneous rocks / igneous | [NPS igneous rocks](https://www.nps.gov/subjects/geology/igneous.htm): broad rock family formed by cooling and solidifying molten rock. |
| Metamorphic rocks / metamorphic | [NPS metamorphic rocks](https://www.nps.gov/subjects/geology/metamorphic.htm): alteration of earlier rock by heat and pressure; alignment occurs in some types. |

## Age labels

The [NPS geologic time scale](https://www.nps.gov/subjects/geology/time-scale.htm)
supports the relative sequence and parent divisions for 26 age labels:
Precambrian; Paleozoic, Mesozoic, Cenozoic; Cambrian, Ordovician, Silurian,
Devonian, Carboniferous, Permian, Triassic, Jurassic, Cretaceous, Paleogene,
Neogene, Quaternary; Mississippian, Pennsylvanian; Tertiary; Paleocene,
Eocene, Oligocene, Miocene, Pliocene, Pleistocene and Holocene.

Two additional labels are supported by the
[International Commission on Stratigraphy official chart](https://stratigraphy.org/chart/),
version 2026/06: **Burdigalian** is a stage within the Miocene Epoch and
**Lutetian** is a stage within the Eocene Epoch. The glossary explicitly marks
their rank as `stage`, distinct from epoch. No relative stage ordering is
provided (`relative_order` is `null`), and no numerical dates are copied.

The [USGS thesaurus](https://apps.usgs.gov/thesaurus/thesaurus-full.php)
specifies Mississippian and Pennsylvanian as subperiods of the Carboniferous.
Some American maps and the NPS educational chart label these as periods.
Precambrian is a broad interval rather than one period. Tertiary is an older
map label covering Paleogene and Neogene. These distinctions are retained.

No numerical boundary ages are included. The ordinal `relative_order` field
runs from oldest to youngest **only among terms with the same rank and parent**.
It cannot compare overlapping divisions or provide a specimen's age.
The [NPS relative dating explanation](https://www.nps.gov/subjects/geology/geotime.htm)
describes the distinction between chronological order and numerical dating.

## Provenance and interpretation

[USGS national geologic map explanation](https://www.usgs.gov/news/national-news-release/usgs-unveils-new-national-geologic-map)
describes mapped units as regional rock/sediment bodies with composition and
age characteristics. The module's specimen caveat is a conservative scope rule:
a regional unit and its age do not identify, source, or date a loose object.
Transport caveats are supported separately above. Observation prompts suggest
features to record on existing surfaces; they are not identification tests.

`explain_unit(material_text, age_text)` translates vocabulary appearing in two
separate fields. It preserves accepted raw strings and every nonmatching text
span, including negations, qualifiers, unknown formations, abbreviations, and
numerical ages. Matching `limestone` inside `no limestone` only opens its
definition and does not affirm limestone's presence. Unknown wording is
explicitly reported, without guessing a formation, fossil, mineral, or find.

Only reviewed aliases and whole words match; generic `ash`, `basaltic`,
`granitic`, and age abbreviations remain untranslated. Terms are returned once
in the order first mentioned. Oversized inputs, non-text values, and text with
non-whitespace control characters are rejected with notices. Surrogate code
points, including manually constructed surrogate pairs, are also rejected.
Normal Unicode characters, including emoji represented as valid code points,
remain text. Display callers must escape text using their usual UI text
rendering. `lookup_term` accepts a
reviewed id, name, or alias. `search_terms` searches names and aliases, with a
bounded result count; an empty query browses the vocabulary.
