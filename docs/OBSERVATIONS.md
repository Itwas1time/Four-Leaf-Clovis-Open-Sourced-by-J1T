# From curiosity to field notes

The integrated workbench adds selectable geological evidence, an in-app
historical-map viewer and saved guided investigations. Start with the
[workbench guide](WORKBENCH.md) for the current step-by-step workflow.

**A little curiosity, Dig deeper.**

Start with something already exposed or a record you can check. Clovis helps
you describe it and keep track of the next question.

## Inspect a find

1. Choose **Inspect a find**. Pick a possible material, or **I am not sure yet**.
2. Select visible features and record size and context. An object in imported
   fill may have come from elsewhere; a branching mineral coating can resemble
   a plant fossil. The guide keeps these competing explanations visible.
   Selected features produce specific questions in the center, such as
   transcribing a mark exactly or recording where a seam ends. Select **Read
   the questions for these features** to jump to the cards. **Record this
   detail** focuses your notes without replacing them. Public town context
   defaults off. Check **Include
   [town]** only when that town belongs with the object. Changing town clears
   the choice without erasing your observations. Included context survives
   downloads and backups; it is not an exact location or verified provenance.
3. Optionally add a still JPEG, PNG or WebP photo under 5 MB. Study both sides, an
   existing edge and a ruler. Zoom, drag, rotate or **Fit photo** to inspect
   details and add a caption. The local Clovis server stores the original file
   without re-encoding or analysis. **Save observation** attaches its reference
   and caption to the dated note. Removing it from the working observation
   leaves the original file and earlier saved notes unchanged.
4. Read the comparison questions, then save or download your written notes.
   Record actions are above the question cards. Open **Read the full comparison
   notes & sources** for the longer guide. Photo instructions remain closed until
   requested so they do not push the useful comparison out of view.
   Take them to a qualified survey, museum or archaeologist for identification.

These guides do not establish identity, age, value or discovery odds. Bottle
seam height alone does not date a fragment. Possible bone should be left in
place; if human remains are suspected, stop disturbance and contact local
authorities. Record without scraping, breaking or digging to expose more.

The authored comparisons link to [NPS artifact examples](https://www.nps.gov/yose/learn/historyculture/facelift-pocket-guide.htm),
[SHA / BLM bottle research](https://secure-sha.org/bottle/),
[USGS rock types](https://pubs.usgs.gov/gip/acidrain/type.html) and
[NPS fossil look-alikes](https://www.nps.gov/subjects/fossils/what-is-a-fossil.htm).
Park-specific collection rules do not establish rights on other land. No
source images, specimen locations or identification model are bundled here.
The complete reviewed NPS artifact-guide text and its source edition can also
be read locally from the glass-bottle guide without following an external link.

## Continue an investigation

- In **Explore**, build a report and choose **Save town context**.
- In **Fieldbook**, open a card. Choose a second saved investigation to
  compare land-use context, mapped units or object features.
- After checking a historical map, select the original town notes. Add a
  follow-up with the map title, date, sheet, source and visible building or use.
  Note what you cannot establish. This creates another dated entry and keeps
  the original report. Compare them to see what your research added.
- Print the selected notes or use the browser's **Save as PDF** option. Markdown
  downloads retain source URLs. Printed notes include the written observations,
  with no photo or unrelated dashboard controls.

The saved map report is a snapshot. Return to Explore a town for a fresh
provider lookup; a new report may differ. User notes and imported reports
are unverified. Imported Markdown is displayed as literal text, so links and
images cannot execute or load inside the saved-note viewer.

## Keep a museum comparison

The **Library** can save a museum reference in this fieldbook with its
recorded facts, collection, catalog identifier and source link. It is labeled
**Museum reference**, separate from an object observation. References never
inherit your selected town and include no photograph. Select the reference
card to read it, compare it with an observation, or prepare a question.

Met reference photographs are optional online requests. The app contacts the
Met's fixed public object API using the catalog object ID only, then loads an
eligible image from the museum host. The provider receives normal network
metadata; your notes, town and local photographs are not part of that request.
Library search and reference saving use the bundled records locally.

## Ask about saved observations

Select saved notes in **Fieldbook**, then open **Prepare a question about these
notes**. Write a question, preview the packet and download or save it. You can
include a possible comparison and a wanted detail without turning either into
an identification. The packet retains the original source and observations.
When the saved notes have personal photos, its ZIP includes readable Markdown
and the original files with their captions. Otherwise it downloads Markdown.
No message is sent.

Select a saved question to **Record a response to this question**. Supply a public
institution or role, the response date and its words or your clearly attributed
summary. Record remaining uncertainty. It becomes a new entry, with the original
notes and question preserved. **Related saved records** connects those entries.
Clovis does not verify the respondent or their identification. The question or
response appears first when reading, downloading or printing; source notes
follow it. Complete fieldbook backups preserve the saved snapshots and photo
references; original files appear once per distinct checksum in a ZIP.

## Keep a backup

Readings are kept in this browser and also merged into the local Clovis
workspace. The status in Fieldbook shows whether the local workspace copy has
finished; if it fails, the browser copy remains. Another browser on this computer
can reopen the local workspace's readings. **Sync saved readings** retries the
merge. Conflicting entries are refused rather than overwritten.

**Download complete workspace** creates one ZIP with saved readings, every
local dig project, all revisions and their original photos. **Restore complete
workspace** merges compatible histories in the local database and refuses
conflicts. Save a copy on another device; this is not cloud synchronization.
The older **Download this fieldbook** and **Restore a fieldbook** controls remain
available for compatible JSON and photo ZIP files. When the expanded readings
exceed the old format's limit, use the complete workspace ZIP.

A workspace holds up to 50 readings, 500 KB per reading and 20 MB of full
reading data. The browser carries compact references for large saved readings;
its notes and references remain bounded to 750 KB. Portable workspace notes and
project revisions share a 64 MB allowance, with up to 100 MB / 1,024 original
photos. Older Clovis releases cannot open the upgraded local database; retain a
complete backup and use the current release to restore it.

Written observations and selected readings are processed by the local app.
Downloaded backups remain wherever you save them. No external service receives
this work. Keep exact sensitive
locations, names, account details and personal information out of shared notes.
There is no account, cloud synchronization or public submission in this workflow.
